# 네이버 자동포스팅 시스템

네이버 블로그 자동 포스팅을 위한 고급 AI 기반 콘텐츠 생성 및 발행 시스템입니다.

## 현재 버전
**v1.2.33** - 최신 안정화 버전

## 주요 기능

### 🤖 AI 기반 콘텐츠 생성
- **GPT 4.1 모델 지원** - 최신 AI 모델로 고품질 콘텐츠 생성
- **맞춤형 프롬프트** - 제목, 인사말, 이미지 스타일 커스터마이징
- **형태소 중복 최소화** - 글 지수 상향을 위한 최적화

### 🎨 이미지 관리
- **AI 생성형 이미지** - 단락별 AI 이미지 생성
- **이미지 스타일 프롬프트** - 원하는 스타일로 이미지 생성
- **자동 이미지 수집** - 주제에 맞는 이미지 자동 선택

### 📝 콘텐츠 수집
- **향상된 글 수집 엔진** - 주제별 정확도 향상
- **다양한 소스 지원** - 웹 크롤링 및 자료 수집
- **드라이브 연동** - 글자료 드라이브 선택 기능

### ⏰ 자동 발행 시스템
- **예약 발행** - 원하는 시간에 자동 발행
- **스케줄러** - 발행 간격 설정 (최대 9999분)
- **간편 예약** - [제목|URL] 형식 지원

### 📊 관리 기능
- **엑셀 내보내기/불러오기** - 대량 콘텐츠 관리
- **다중 계정 관리** - 여러 네이버 계정 지원
- **공지팝업 시스템** - 사용자 알림 기능

### 🎬 미디어 지원
- **동영상 업로드** - 블로그 동영상 자동 업로드
- **최적화된 대기시간** - 안정적인 미디어 업로드

## 시작하기

### 필수 요구사항
- Node.js 14 이상
- 네이버 계정
- GPT API 키

### 설치
```bash
npm install
```

### 설정
```bash
# 환경 변수 설정
cp .env.example .env
# .env 파일에 네이버 계정 및 GPT API 키 입력
```

### 실행
```bash
npm start
```
